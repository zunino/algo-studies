## Goal

To implement the Perceptron algorithm, a binary classifier that can be trained
on labeled samples (supervised learning). The dataset used consists of N x N
bitmaps representing either **rectangles** or **circles**. The training process
is configured so that the output neuron should fire only when it is presented
with a circle.
